# 내 학습 노트

이 사이트는 Claude와 함께 공부한 내용을 마크다운 노트로 정리해 모아 두는 곳입니다. 노트는 내 PC의 학습 기록 폴더에서 쓰고, GitHub 저장소 `study-notes`에 올리면 이 사이트에 웹 페이지로 나타납니다.


## 마크다운 기본 문법 한눈에 보기

마크다운은 글자 앞뒤에 몇 가지 기호를 붙여 제목, 목록, 표 같은 모양을 정하는 글쓰기 방식입니다. 아래 항목마다 먼저 적는 법을 회색 상자(코드 블록)로 보이고, 이어서 그 글이 웹 페이지에서 보이는 모양을 둡니다. 이 파일(`index.md`)을 메모장으로 열어 이 페이지와 나란히 놓으면 기호가 어떤 모양으로 바뀌는지 볼 수 있습니다.

### 제목

줄 맨 앞에 `#`을 붙이면 제목이 됩니다. `#`의 개수가 제목의 단계이고, `#`과 글자 사이에 빈칸 한 칸을 둡니다.

```markdown
# 1단계 제목
## 2단계 제목
### 3단계 제목
```

보이는 모양: 이 페이지 본문 맨 위의 "내 학습 노트"가 1단계 제목, "마크다운 기본 문법 한눈에 보기"가 2단계 제목, 지금 읽는 "제목"이 3단계 제목입니다. 1단계 제목은 노트 맨 위에 한 번만 쓰고, 본문은 2단계와 3단계 제목으로 나눕니다.

### 문단

문단과 문단 사이에는 빈 줄을 하나 둡니다. 빈 줄 없이 줄만 바꾸면 앞 줄과 같은 문단으로 이어져 보입니다.

```markdown
첫째 문단의 첫 줄입니다.
빈 줄 없이 바꾼 이 줄은 앞 줄에 이어집니다.

빈 줄 다음은 새 문단입니다.
```

보이는 모양:

첫째 문단의 첫 줄입니다.
빈 줄 없이 바꾼 이 줄은 앞 줄에 이어집니다.

빈 줄 다음은 새 문단입니다.

### 강조와 인라인 코드

별표 두 개로 감싸면 굵게, 별표 한 개로 감싸면 기울여 보입니다. 명령이나 파일 이름은 억음 부호(백틱, 키보드 숫자 1 왼쪽의 기호)로 감쌉니다.

```markdown
**중요한 내용**, *참고할 내용*, `git push`
```

보이는 모양: **중요한 내용**, *참고할 내용*, `git push`

### 목록

순서가 없는 목록은 줄 맨 앞에 `-`와 빈칸 한 칸을 둡니다.

```markdown
- 마크다운 노트 쓰기
- GitHub에 올리기
- 사이트에서 확인하기
```

보이는 모양:

- 마크다운 노트 쓰기
- GitHub에 올리기
- 사이트에서 확인하기

### 번호 목록

순서가 있는 목록은 숫자와 마침표, 빈칸 한 칸으로 시작합니다.

```markdown
1. 노트를 쓴다.
2. 커밋한다.
3. GitHub에 올린다.
```

보이는 모양:

1. 노트를 쓴다.
2. 커밋한다.
3. GitHub에 올린다.

### 인용

다른 자료에서 가져온 문장이나 눈에 띄게 둘 문장은 줄 맨 앞에 `>`와 빈칸 한 칸을 둡니다.

```markdown
> 학습 노트는 나중의 나에게 보내는 설명서입니다.
```

보이는 모양:

> 학습 노트는 나중의 나에게 보내는 설명서입니다.

### 코드 블록

여러 줄의 코드나 명령은 억음 부호 세 개로 시작하는 줄과 끝나는 줄 사이에 둡니다. 시작하는 줄의 억음 부호 뒤에 언어 이름(예: `bash`)을 적으면 그 언어에 맞게 색이 입혀질 수 있습니다. 상자 안의 글자는 기호까지 적은 그대로 보입니다.

~~~markdown
```bash
git add index.md
git commit -m "사이트 첫 화면 추가"
git push
```
~~~

보이는 모양:

```bash
git add index.md
git commit -m "사이트 첫 화면 추가"
git push
```

### 표

`|`로 칸을 나누고, 둘째 줄의 `---`로 헤더 행(칸 이름을 적는 첫 줄)과 내용 행을 가릅니다.

```markdown
| 명령 | 하는 일 |
|---|---|
| `git add` | 커밋에 넣을 파일을 고른다 |
| `git commit` | 고른 파일로 기록을 남긴다 |
| `git push` | 남긴 기록을 GitHub에 올린다 |
```

보이는 모양:

| 명령 | 하는 일 |
|---|---|
| `git add` | 커밋에 넣을 파일을 고른다 |
| `git commit` | 고른 파일로 기록을 남긴다 |
| `git push` | 남긴 기록을 GitHub에 올린다 |
